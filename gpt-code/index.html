Self-contained review file with a 66-book Protestant Bible menu. No framework, font downloads, account, or API key.

The service is rate-limited and has no uptime guarantee. Chapters are cached in memory for this tab; there is no whole-Bible download. Word-difference highlighting and visual overlays are not included in this first comparison step.
